# FarbTheme – Mystania UI Farbschemata

Resourcepacks für die Vanilla-Oberflächen (Inventar, Truhen, Rezeptbuch, Hotbar, Tooltips, Dialog-Knöpfe) in jeder
Minecraft-Farbe. Der Server (Plugin GuiTest) schickt jedem Spieler das Pack seiner gewählten Farbe (`/farbe`)
zusätzlich zum Nexo-Pack. Mystania (Lila) ist die Standardfarbe und steckt bereits im Nexo-Pack.

Dateien: `mystania_ui-<farbe>.zip` – white, light_gray, gray, black, brown, red, orange, yellow, lime, green,
cyan, light_blue, blue, purple, magenta, pink.

Erzeugt mit `./gradlew colorPacks` (oder `nexoPack`) im Projekt „Gui Test“ (Ordner `ColorPacks`). Nach jeder Änderung hier neu
hochladen **und** die neue Plugin-JAR einspielen – das Plugin prüft die SHA-1-Hashes der Packs.
